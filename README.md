## Описание проектов 

Проект №1: Конфигурация «Учет ГСМ» (1С:Предприятие 8.3)
Цель проекта: автоматизация складского учета топлива, контроля заправок автопарка и списания ГСМ по нормам пробега.

Реализованная функциональность:
Архитектура данных: спроектирована структура метаданных с нуля (справочники номенклатуры/видов топлива, складов и транспортных средств с хранением технических характеристик: разрешенный вид топлива, объем бака, норма расхода).

Документооборот и бизнес-логика (проведение документов):
o	«Поступление топлива» — фиксация прихода ГСМ на склады и автоматическая регистрация актуальных цен.
o	«Выдача топлива» — распределение ГСМ по автомобилям (работа с табличной частью). При проведении реализован многоуровневый контроль: проверка наличия достаточного остатка на складе, валидация соответствия вида топлива конкретному ТС и контроль непревышения объема бензобака автомобиля.
o	«Расход топлива по одометру» — фиксация пробега и списание ГСМ. На управляемой форме реализован программный расчет нормативного расхода по кнопке на основе разницы показаний одометра, а при проведении выполняется проверка остатков топлива в баке.

Регистры и учет:
o	Регистры накопления (вид — Остатки) для оперативного контроля остатков ГСМ в разрезе складов и каждого автомобиля.
o	Периодические регистры сведений для хранения истории цен на топливо и динамики показаний одометра (получение среза последних).

Стек и навыки: 1С:Предприятие 8.3 (управляемое приложение), модули объектов и форм, работа с табличными частями, запросы (в т.ч. к виртуальным таблицам остатков и среза последних), обработка проведения.


Проект №2: Конфигурация «Хранилище файлов и фрагментов кода» (1С:Предприятие 8.3)
Цель проекта: создание единого рабочего пространства на рабочем столе для систематизации, хранения и быстрого поиска полезных файлов и сниппетов кода по тегам.
Реализованная функциональность:
Архитектура и хранение данных: спроектированы иерархические справочники («Внешние файлы», «Фрагменты кода») с использованием типа ХранилищеЗначения для оптимизации хранения двоичных данных и больших объемов текста (в кодировке UTF-8), а также табличными частями для привязки поисковых тегов.

Автоматизированное рабочее место: разработан единый интерфейс на рабочем столе с динамическим переключением режимов работы («Файлы» / «Фрагменты кода»), отображением дерева элементов и карточкой предпросмотра/редактирования.

Работа с файлами и асинхронность: реализована асинхронная загрузка файлов на сервер через временное хранилище (НачатьПомещениеФайлаНаСервер, ОписаниеОповещения), сохранение файлов на диск пользователя, а также программное извлечение и отображение текста кода в поле текстового документа.

Фильтрация: настроена динамическая фильтрация списков по набору тегов через параметры динамического списка, программное управление видимостью и доступностью элементов формы, а также контроль несохраненных изменений с интерактивным диалогом подтверждения (ПоказатьВопрос).

Стек и навыки: 1С:Предприятие 8.3 (управляемые формы, клиент-серверное взаимодействие), ХранилищеЗначения, временное хранилище, двоичные данные, асинхронные вызовы (ОписаниеОповещения), динамические списки, стандарты разработки 1С (структурирование кода по областям).
